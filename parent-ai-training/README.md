### 시간이 부족할 때 덜어낼 순서

43장은 90분에 빠듯합니다. 아래 순서로 빼면 흐름이 끊기지 않습니다.

1. **34장** AI for Good — 33장 태국 사례로 대체 가능
2. **37장** 근거 없는 65% 수치 — 31장 사실 확인 활동에 흡수 가능
3. **20장** 종이 읽기 연구 — 19장 도구 구분에 한 문장으로 요약
4. **21장** PISA — 17장 신호등에서 '용도가 기준'만 언급
5. **16장** Family Link 설정 — 유인물로 대체

다섯 장을 빼면 38장이 되어 여유가 생깁니다. 반대로 시간이 남으면
9장(인지 부채)과 24장(과제 종류)에 시간을 더 쓰시길 권합니다.
