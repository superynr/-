### 슬라이드를 추가·이동할 때

`build.py`의 `ORDER` 목록이 곧 발표 순서입니다. 목록에 넣고 빼기만 하면
쪽번호가 자동으로 다시 매겨집니다. 본문이나 발표자 노트에서 다른 장을
가리킬 때는 숫자 대신 `{이름}장` 토큰을 쓰면(예: `{promise}장`) 빌드할 때
실제 번호로 바뀌므로, 순서가 바뀌어도 어긋나지 않습니다.
